# GymAppEditBot — отдельный Telegram-топик для каждого проекта

Один Telegram-бот [@GymAppEditBot](https://t.me/GymAppEditBot) работает с двумя проектами в **разных топиках одной супергруппы**:

| Топик | GitHub Issues | Команда привязки |
| --- | --- | --- |
| 🏋️ Gym App | [pavelmashina/gym-app](https://github.com/pavelmashina/gym-app/issues) | `/bind gym` |
| 🐾 Рядом — питомцы | [pavelmashina/ryadom-app](https://github.com/pavelmashina/ryadom-app/issues) | `/bind ryadom` |

**Существующая привязка Gym App сохранена автоматически.** Новая настройка нужна только для топика «Рядом», если топик Gym App уже был подключён.

## Подключение второго топика

1. В **той же группе Telegram** создай новый топик, например «🐾 Задачи — Рядом». Режим «Темы» (Topics) должен быть включён в настройках группы.
2. Открой именно новый топик.
3. Отправь **с аккаунта владельца бота** команду **`/bind ryadom`** (или `/bind@GymAppEditBot ryadom`).
4. Бот должен подтвердить: **«Топик закреплён за проектом Рядом»**.
5. Старый топик Gym App продолжит работать без изменений. Если настраиваешь с нуля, в гим-топике отправь `/bind gym`.

Топик закрепляется за конкретным проектом. **Переключать проект внутри группового топика нельзя.** Чтобы поставить задачу другому приложению, перейди в соответствующий топик.

## Подача задачи

1. Зайди в нужный топик и нажми **🆕 Новая задача**.
2. Отправь текст и при необходимости до шести скриншотов JPG/PNG/WebP (до 8 МБ каждый).
3. Нажми **✅ Отправить** — Issue появится в GitHub-репозитории этого топика, а ссылка вернётся сюда же.

Кнопка выбора проекта **не требуется в топиках**. Для личного чата с ботом она остаётся доступной. В каждом топике участники имеют отдельные черновики, а сообщения из других/непривязанных топиков бот игнорирует. Если ранее в черновике одного топика были материалы для другого проекта, бот попросит сначала удалить старый черновик кнопкой «❌ Отмена».

## Подключение бота и права доступа

- Бот должен быть добавлен в Telegram-супергруппу. Если обычные сообщения не доходят до него, отключи Privacy Mode через BotFather или назначь бота администратором. После изменения Privacy Mode может понадобиться пере-добавить его в группу.
- `/bind gym`, `/bind ryadom` и `/unbind` выполняются **только владельцем**, Telegram ID которого указан в `TELEGRAM_ALLOWED_USER_ID`.
- `/unbind` отвязывает **только тот топик**, в котором отправлена команда. Для смены проекта сначала отвяжи старый топик и привяжи новый.
- Один проект может быть привязан **к одному топику на группу**, но другая Telegram-группа может иметь свои привязки.
- Дополнительные участники присылают `/id`; владелец выдаёт доступ командой `/allow 123456789`, отзывает — `/revoke 123456789`. `/users` показывает разрешённые ID.
- Токен GitHub должен иметь **Issues → Read and write** для обоих репозиториев; альтернативно в Supabase Secrets можно добавить отдельный `GITHUB_ISSUES_TOKEN_RYADOM` для «Рядом». [Подробнее](telegram-multi-project.md).

## Безопасность и совместимость

- Telegram webhook защищён `TELEGRAM_WEBHOOK_SECRET`, доступ пользователей проверяется по ID.
- Привязки сохраняются в `public.telegram_issue_bound_topics` по паре **(group_id, thread_id)** с конкретным `project`; старая привязка автоматически получила проект `gym-app`.
- Черновики групповых задач разделены ключом `group_id:thread_id:user_id`.
- Скриншоты загружаются в публичный Supabase Storage bucket и отображаются в публичных GitHub Issues. Не отправляй секреты и личную информацию.
- Голосовые сообщения временно отключены.

## Проверка

1. Отправь `/project` в старом топике: бот должен написать, что он привязан к **Gym App**.
2. В новом топике отправь `/bind ryadom` и `/project`: ответ должен указывать **«Рядом»**.
3. В новом топике создай текстовую задачу и убедись, что она появилась **только** в [Issues ryadom-app](https://github.com/pavelmashina/ryadom-app/issues).
4. Убедись, что ссылки и подтверждения приходят именно в исходный топик, а в другом топике бот не реагирует.
5. Проверь метки **«Новая задача» → «Выполнена» → «Проверена»**: они настроены в обоих репозиториях.
