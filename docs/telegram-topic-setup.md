# GymAppEditBot — кнопки, групповой топик и участники

Бот создаёт [GitHub Issues gym-app](https://github.com/pavelmashina/gym-app/issues) по тексту, голосовым и скриншотам в Telegram.

## Интерфейс

При `/start` и `/rules` бот показывает правила и постоянные кнопки:

- **🆕 Новая задача** — начать собирать материалы в черновик;
- **✅ Отправить** — создать Issue из черновика и получить ссылку;
- **❌ Отмена** — очистить свой черновик;
- **📖 Правила** — вывести инструкцию;
- **🆔 Мой ID** — показать числовой Telegram user ID.

В личном чате одиночные текстовые и голосовые задачи можно отправлять сразу. В групповой теме нужно сначала нажать «Новая задача», добавить текст/голос/скриншоты (до 6), затем «Отправить». Драфты разных участников не пересекаются.

## Подключение существующего топика

1. Добавь [@GymAppEditBot](https://t.me/GymAppEditBot) **в супергруппу**, где уже существует нужный топик (боты присоединяются к группе, а не напрямую к одному топику).
2. В BotFather выбери **/mybots → GymAppEditBot → Bot Settings → Group Privacy → Turn off** или используй **/setprivacy → GymAppEditBot → Disable**. При смене privacy mode **удали бота из группы и добавь снова**. Альтернатива: назначить бота администратором группы. В обоих случаях бот технически получает сообщения из всей группы; сам обработчик игнорирует чужие топики и неавторизованных отправителей.
3. Открой **именно существующий нужный топик** в группе.
4. **С аккаунта владельца бота** (ID из `TELEGRAM_ALLOWED_USER_ID`) отправь `/bind@GymAppEditBot` или `/bind`.
5. Бот должен ответить в этом же топике: **«Этот топик привязан»** и показать правила/кнопки.
6. Для смены топика повтори `/bind` в другом топике той же группы. Для отключения текущего топика отправь `/unbind`.
7. При использовании групповых топиков Webhook не нужно менять: уже настроено получение Telegram `message` updates.

Обработчик никогда не создаёт Issue из сообщений другого топика. Для безопасности в выбранном топике обязательна кнопка **«Новая задача»** — обычные посторонние сообщения не попадают в GitHub.

## Добавление участников

Дополнительные пользователи открывают бота в личных сообщениях или в связанном топике и отправляют `/id` либо нажимают «Мой ID». Затем владелец бота пишет:

- `/allow 123456789` — разрешить конкретному Telegram ID создавать Issues.
- `/revoke 123456789` — отозвать разрешение.
- `/users` — просмотреть доступные IDs (до 50 строк).

Команды управления пользователями доступны **только** владельцу; пользователь с доступом может добавлять задачи в личке с ботом или в привязанном топике, но не может менять список участников.

## Безопасность

- Разрешённые Telegram IDs хранятся в `public.telegram_issue_authorized_users`; привязка топика — в `public.telegram_issue_bound_topics`, RLS включён, доступ anon/authenticated запрещён.
- Владелец определяется секретом `TELEGRAM_ALLOWED_USER_ID`, добавленным ранее.
- Черновики из группы изолированы ключом `group_id:thread_id:user_id`. Старые личные черновики совместимы.
- Вебхук по-прежнему защищён `TELEGRAM_WEBHOOK_SECRET`.
- **Скриншоты публичны**, так как GitHub репозиторий публичный, а картинки встроены через публичное хранилище.
- Отключение Privacy Mode позволяет Telegram-боту получать сообщения всей группы; обработчик использует только сообщения выбранного топика и разрешённых пользователей.

## Быстрая проверка

1. В личке отправь `/rules` — появляются кнопки.
2. В нужном топике отправь `/bind` с аккаунта владельца — получаешь правила.
3. Дополнительный участник получает `/id` и его ID добавляется через `/allow ID`.
4. Участник в топике нажимает «Новая задача», отправляет скриншот и голос, затем «Отправить».
5. Убедись, что новая Issue создана, скриншот отображается и ссылка приходит **в тот же топик**.
6. Попробуй написать в соседнем топике — бот должен проигнорировать сообщение.
