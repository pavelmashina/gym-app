# Gym App — Beta 1.0 scope

## Цель Beta 1.0

Довести приложение до состояния, в котором около 10 реальных пользователей могут самостоятельно зарегистрироваться, выбрать или создать программу тренировок, провести тренировку, сохранить результаты и увидеть историю без ручной помощи разработчика.

## Обязательный пользовательский путь

1. Регистрация по email и паролю.
2. Вход и выход из аккаунта.
3. Главный экран с актуальной датой и запланированной тренировкой.
4. Просмотр каталога упражнений.
5. Создание/выбор программы тренировок.
6. Присоединение к программе и формирование расписания.
7. Запуск тренировки отдельной кнопкой «Начать тренировку».
8. Ведение подходов: вес, повторения, разминка/рабочий подход.
9. Общий таймер тренировки.
10. Предыдущий результат, лучший подход и заметка по упражнению.
11. Изменение порядка упражнений во время тренировки.
12. Брошенная тренировка с возможностью продолжить ту же сессию.
13. Завершение или отмена тренировки.
14. История тренировок и базовая статистика.
15. Сохранение данных после перезагрузки, выхода из аккаунта и входа с другого устройства.

## Логика WorkoutSession для Beta

Статусы:

- `ACTIVE`
- `ABANDONED`
- `COMPLETED`
- `CANCELLED`

Основной переход:

`ACTIVE → ABANDONED → ACTIVE → COMPLETED`

Дополнительно:

- одновременно у пользователя может быть только одна `ACTIVE` WorkoutSession;
- `ABANDONED` не создаёт новую сессию — пользователь продолжает существующую;
- разминка хранится в истории, но не входит в рабочий тоннаж;
- изменение порядка упражнений в сессии не изменяет исходную программу;
- отмена тренировки возвращает запланированную тренировку в состояние `PLANNED`;
- пропуск тренировки — отдельное действие со статусом `SKIPPED`.

## Что НЕ входит в Beta 1.0

Эти функции проектируем так, чтобы их можно было добавить позже, но не задерживаем ими первую бету:

- подписки и платежи;
- рейтинги, сезоны и глобальные таблицы лидеров;
- полноценный дневник питания;
- готовые рационы;
- справочник спортивного питания;
- сложные уведомления;
- полноценный offline-first режим;
- App Store / Google Play;
- расширенная админ-панель.

## Техническая архитектура Beta

### Frontend

- React + Vite.
- Код и история версий — GitHub.
- Production frontend — GitHub Pages.

### Backend / данные

- Supabase Auth — аккаунты.
- Supabase PostgreSQL — программы, расписание, тренировки, подходы, история.
- Row Level Security — пользователь имеет доступ только к собственным данным.
- Supabase Storage — только если в Beta понадобятся пользовательские файлы.

Отдельный постоянно работающий сервер для Beta 1.0 не требуется.

## Критерии готовности Beta 1.0

Beta считается готовой, когда выполнены все условия:

- два разных пользователя не видят данные друг друга;
- новый пользователь способен пройти основной путь без помощи разработчика;
- активная тренировка переживает обновление страницы;
- после logout/login данные остаются;
- данные доступны при входе с другого устройства;
- нельзя случайно создать две активные тренировки;
- завершённая тренировка появляется в истории;
- предыдущий результат корректно показывается в следующей тренировке;
- критические ошибки не приводят к потере уже сохранённых подходов;
- приложение стабильно работает в Safari на iPhone и в современном Chrome.

## Порядок реализации

1. React/Vite foundation без изменения текущего дизайна.
2. Supabase project + схема БД.
3. Auth + profiles.
4. Каталог упражнений.
5. Programs + ProgramWorkouts.
6. UserProgram + расписание.
7. WorkoutSession + sets + timer.
8. История + previous result + best set.
9. Базовая статистика.
10. PWA shell.
11. Тестирование 1 пользователем.
12. Тестирование 2–3 пользователями.
13. Закрытая Beta примерно на 10 пользователей.
