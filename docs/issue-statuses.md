# Статусы задач Gym App

Все задачи хранятся в [GitHub Issues](https://github.com/pavelmashina/gym-app/issues). У каждой задачи есть **один** статус, реализованный через GitHub label:

| Статус | Значение | Состояние GitHub Issue |
| --- | --- | --- |
| **Новая задача** | Задача поступила и ещё не принята владельцем | Open |
| **Выполнена** | Исполнитель внес изменения; владелец ещё не проверил результат | Open |
| **Проверена** | Владелец лично проверил и принял результат | Closed |

## Как менять статус

1. Открой нужный Issue в GitHub.
2. Справа в разделе **Labels** нажми значок настроек.
3. Выбери новый статус — **Выполнена** после внесения правок или **Проверена** после личной проверки.
4. GitHub Actions автоматически уберёт старую статусную метку. Остальные метки (например, тип задачи) сохраняются.
5. Если проверенную задачу нужно вернуть на доработку, открой Issue заново: его статус автоматически станет **Новая задача**.

## Автоматические правила

- Новые GitHub Issues (включая созданные из Telegram через GymAppEditBot) получают **Новая задача** автоматически.
- При первом развёртывании статусы создаются и всем **открытым** Issues без статуса назначается **Новая задача**.
- Ранее закрытые Issues не трогаются: их нельзя считать проверенными без подтверждения владельца.
- Переход в **Проверена** закрывает Issue; переход в два предыдущих статуса оставляет или возвращает его открытым.
- Изменения выполняются через [GitHub Actions](https://github.com/pavelmashina/gym-app/actions/workflows/issue-statuses.yml) с разрешением `issues: write`.
- **Только владелец продукта** решает, что задача проверена; отдельная ИИ-проверка не предусмотрена.

Для просмотра задач по статусу можно использовать фильтр в списке Issues: `label:"Новая задача"`, `label:"Выполнена"`, `label:"Проверена"`. Проверенные задачи нужно искать также среди **Closed**.
